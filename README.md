# Cookie Clicker Web App

A simple, interactive web application featuring a centered cookie image and a click counter.

## Features

- **Centered Cookie Graphic**: An SVG-rendered chocolate chip cookie styled and placed right in the middle of the screen.
- **Click Counter**: Displays the number of times the cookie has been clicked with visual feedback (+1 floating text animation).
- **Cookie-Based Persistence**: Uses HTTP browser cookies (`document.cookie`) to save and persist the click count across page reloads and browser sessions.
- **Modular Code**: JavaScript logic is cleanly decoupled into `script.js`.
- **Reset Option**: A "Reset Count" button to reset the click counter back to zero.
- **Responsive & Modern Design**: Clean styling with soft gradients, glassmorphism card effect, and smooth click animations.

## How to Run

1. Open `index.html` in any web browser.
2. Click on the cookie to increase the counter!
